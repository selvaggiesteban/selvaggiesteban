<h2>Evaluación de infraestructura y arquitectura tecnológica para aplicación web en producción</h2>


<p>Evaluar la infraestructura y arquitectura tecnológica necesaria para mantener una aplicación web en funcionamiento en un entorno real. Aunque el diseño simplifica cada capa en un bloque horizontal, dentro de ese cilindro se agrupan los siguientes 12 componentes del desarrollo de software:</p>

<ul>
<li><strong>Frontend:</strong> La interfaz de usuario gráfica e interactiva.</li>
<li><strong>Backend / APIs:</strong> La lógica del negocio y las conexiones entre servicios.</li>
<li><strong>Database:</strong> El almacenamiento persistente de datos (bases de datos).</li>
<li><strong>Servers:</strong> El hardware o instancias virtuales donde corre la aplicación.</li>
<li><strong>Networking:</strong> Configuración de redes, DNS y enrutamiento.</li>
<li><strong>Cloud Infrastructure:</strong> Proveedores en la nube (AWS, Google Cloud, Azure) que alojan la solución.</li>
<li><strong>CI / CD Pipelines:</strong> Integración y despliegue continuo de código.</li>
<li><strong>Security:</strong> Autenticación, cifrado de datos y gestión de permisos.</li>
<li><strong>Containers:</strong> Empaquetado del sistema para entornos aislados (Docker, Kubernetes).</li>
<li><strong>CDN:</strong> Redes de distribución de contenido para reducir la latencia global.</li>
<li><strong>Monitoring & Logging:</strong> Seguimiento de errores, registros y métricas de rendimiento.</li>
<li><strong>Backups & Recovery:</strong> Copias de seguridad y planes de recuperación ante fallos.</li>
</ul>
