## Programación web que resuelve problemas reales

Necesitás un sistema que no encontrás en ningún lado, una API que conecte tus herramientas, o una automatización que te ahorre horas de trabajo manual? Soy programador web con experiencia en desarrollo backend y frontend, y me especializo en crear soluciones a medida para negocios que necesitan más que un WordPress genérico.

No trabajo con templates ni soluciones copypaste. Cada proyecto se programa desde cero, usando las tecnologías más adecuadas para tu caso. Si necesitás una API para tu app, un sistema de gestión para tu empresa, o una integración entre plataformas, me encargo del código completo.

## Tecnologías y servicios de programación

Trabajo con Python, JavaScript, TypeScript, Node.js, FastAPI, React, Astro y otras tecnologías actuales. Desarrollo APIs RESTful y GraphQL, bases de datos SQL y NoSQL, sistemas de autenticación, integraciones con servicios de terceros, y automatizaciones con inteligencia artificial.

Mi código es limpio, documentado y mantenible. No hago atajos que te generen problemas a futuro. Cada función está pensada para escalar y ser fácil de modificar cuando tu negocio crezca.
